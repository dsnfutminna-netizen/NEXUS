# NEXUS pilot design

## Purpose

Help students understand their skills and take one useful next step. The interface is a working tool: plain language, visible navigation, readable comparisons, and honest recommendations.

## Palette

- Green `#126B45`: primary actions, links, selection, and positive status.
- White `#FFFFFF`: main background.
- Pale green `#F2F7F4`: input and secondary surfaces.
- Dark green `#18382B`: primary text; `#476253`: secondary text.
- Red `#B42332`: errors, caution, focus outlines, and a restrained brand accent.
- Labels and icons accompany status colors. No decorative gradients or unrelated accent colors.

## Components

- Source Sans through Streamlit's bundled sans-serif UI; body and form text at least 16px.
- Controls aim for a 44px minimum height and visible keyboard focus.
- Authentication width: 520px maximum. Main workspace: 1100px maximum.
- Always-visible Navigate selector replaces the overlay sidebar on every screen.
- Skill comparisons wrap vertically; do not require horizontal table scrolling.
- Opportunities use separated rows, a single coverage number, and expandable details.
- Green means an action or progress, not verified acceptance or job eligibility.

## Content

- Say tagged skills coverage, never acceptance chance or an unqualified match percentage.
- Clearly separate live and sample listings; samples have no application action.
- Every empty or complete state explains what happened and suggests a next step.
- Feedback has no default scores and does not ask users to prove the product works.
